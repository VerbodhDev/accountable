## Records

### Organization

A company the owner does business with.

| Field | Required | Rule |
|---|---|---|
| Name | Yes | The label in tables and on the pipeline |
| Website | No | Shown as a link when it is present |
| Industry | No | Free text |
| Notes | No | Free text |
| Added by | Yes | The person who added it. The organization page shows this name |
| Last changed by | Yes | The person who last changed it. The page does not show this name |

An organization has many contacts and many deals.
