### Contact

A person the owner deals with. A lead is a contact with status Lead. There is no separate lead list.

| Field | Required | Rule |
|---|---|---|
| Name | Yes | |
| Email | No | |
| Phone | No | |
| Job title | No | |
| Organization | No | One organization, or none |
| Status | Yes | Lead, Qualified, or Customer. A new contact starts as Lead |
| Added by | Yes | The person who added it. The contact page shows this name |
| Last changed by | Yes | The person who last changed it. The page does not show this name |
